# Victor Hugo Miranda · Portfólio

Portfólio de desenvolvimento de software, com apresentação de serviços, tecnologias e projetos de sites e sistemas.

## Conteúdo

- Apresentação profissional.
- Serviços de sites, landing pages, sistemas sob medida e produtos SaaS.
- Projetos Pagels, AurumFlow, MeuFiado e experiência digital de casamento.
- Interface responsiva e navegação por seções.

## Tecnologias

HTML, CSS e JavaScript, sem etapa de compilação.

## Executar localmente

Na raiz do projeto, com Python instalado:

```bash
python -m http.server 8080
```

Abra http://localhost:8080.

## Estrutura

| Arquivo ou pasta | Responsabilidade |
|---|---|
| `index.html` | Apresentação, serviços e projetos |
| `styles.css` | Identidade visual e responsividade |
| `script.js` | Interações da página |
| `assets` | Ilustrações e identidade visual |
